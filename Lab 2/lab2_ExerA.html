About the Event

CodeQuest: The Coding Adventure Workshop is a one-day event organised by the Faculty of Computer Science and Mathematics (FSKM), UMT.

Activity 1: Introduction to Programming

Participants will learn the fundamentals of programming and understand how to solve problems using logical thinking. The session will introduce
basic programming concepts and help students develop their coding skills. It is suitable for beginners who want to gain more knowledge about programming.

Activity 2: Web Development Workshop

Participants will learn how to create and structure web pages using HyperText Markup Language (HTML). The workshop will introduce basic HTML
elements, including headings, paragraphs, links, images, tables and forms. Participants will also gain hands-on experience in building a simple website
and understanding how HTML is used in web development.

Activity 3: Debugging Challenge

Participants will identify and fix errors in programming code through a series of debugging tasks. This activity aims to improve their problem-solving
skills, logical thinking and understanding of programming concepts. Participants will also learn how to detect common coding mistakes and develop more
effective debugging techniques.
